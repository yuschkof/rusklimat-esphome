# rusklimat-esphome

Внешний компонент ESPHome для управления кондиционером Rusklimat по UART (ESP32 вместо штатного Wi-Fi-модуля).

## Подключение

```yaml
external_components:
  - source: github://yuschkof/rusklimat-esphome@main
    components: [rusklimat]

uart:
  id: ac_uart
  tx_pin: GPIO17
  rx_pin: GPIO16
  baud_rate: 9600

climate:
  - platform: rusklimat
    id: main_ac
    name: "Кондиционер"
    uart_id: ac_uart
    # всё ниже — необязательно, ссылки на template-сущности
    display_switch: sw_display
    ionizer_switch: sw_ionizer
    sleep_switch: sw_sleep
    timer_number: num_timer
    timer_remaining_sensor: sens_timer_remaining
```

Переключатели, таймер и датчик остатка — обычные `template`-сущности, которые вызывают методы
`set_display()`, `set_ionizer()`, `set_sleep()`, `set_timer_hours()`.

Турбо — дополнительная скорость вентилятора «Турбо» в карточке климата; выключает Тихий и Сон.
Сон — отдельный переключатель: работает вместе с Тихим и любой скоростью, но выключает Турбо.
Если для Турбо нужен ещё и отдельный переключатель, подключите его через `turbo_switch` и `set_turbo()`.
Полный пример — [rusklimat-ac.yaml](rusklimat-ac.yaml).

> **Важно:** у template-переключателей ставьте `restore_mode: DISABLED`. Со значением по умолчанию
> (`ALWAYS_OFF`) при каждой загрузке ESP выполняется `turn_off_action`, и кондиционер выключается.

Поддерживается: питание, режимы (auto/cool/dry/heat/fan), уставка 16–32 °C, температура в комнате,
вентилятор (auto/quiet/low/medium/high/Турбо), жалюзи (вертикаль/горизонталь/обе), дисплей, ионизатор, сон,
таймер выключения 1–24 ч.

## Протокол

9600 8N1. Пакет: `AA <len> <type> ... <crc>`, `len` — число байт после него без CRC,
CRC — сумма всех предыдущих байт по модулю 256.

Запрос статуса (каждые `update_interval`, по умолчанию 2 с): `AA 02 01 AD`.

Статус (type `0x01`, от кондиционера), команда (type `0x02`, от ESP) и ACK (type `0x02`, от кондиционера) — по 22 байта:

| Байт | Значение |
|---|---|
| 3 | питание: `00` выкл, `01` вкл |
| 5 | вертикальные жалюзи: `00` качание, `06` стоп |
| 6 | `0x02` горизонтальные жалюзи; в команде базово `0x18` |
| 7 | режим: `00` auto, `01` cool, `02` dry, `03` heat, `04` fan |
| 8 | флаги, независимые: `0x10` дисплей, `0x08` турбо, `0x04` тихий, `0x02` ионизатор, `0x01` сон |
| 9 | вентилятор: `00` auto, `01`–`03` low–high (тихий — флаг в [8], скорость не меняет) |
| 10 | уставка, °C |
| 11 | температура в комнате, °C (в команде `00`) |
| 12 | таймер: `02` активен, `00` нет |
| 13 | таймер, часы |
| 14 | таймер, минуты |
| 21 | CRC |

## Отладка

На уровне `INFO` в логе видны отправляемые команды и изменения статуса побайтно (`Diff: [8]:10->18`),
на `DEBUG` — ещё и ACK от кондиционера.

# rusklimat-esphome

Внешний компонент [ESPHome](https://esphome.io) для управления по UART кондиционерами, которые продаёт «Русклимат»
(GoldStar и родственные бренды): ESP32 подключается вместо штатного Wi-Fi-модуля, кондиционер появляется
в Home Assistant как климат-устройство с дополнительными переключателями.

## Проверено на

| | |
|---|---|
| Кондиционер | GoldStar GSAC/GSACI |
| Плата | ESP32-WROOM-32 (ESP32 DevKit, `esp32dev`) |
| ESPHome | 2026.9.1, фреймворк ESP-IDF |
| Home Assistant | интеграция ESPHome, шифрование API |

С другими моделями того же семейства (тот же разъём Wi-Fi-модуля и протокол `AA ...`) компонент,
скорее всего, тоже заработает, но это не проверялось. Если проверите — откройте issue с моделью.

## Возможности

- питание, режимы auto / cool / dry / heat / fan, уставка 16–32 °C, температура в комнате;
- скорость вентилятора auto / low / medium / high;
- жалюзи: вертикальные, горизонтальные, обе;
- переключатели: Тихий, Турбо, Сон, Дисплей, Ионизатор (Тихий и Сон совместимы, Турбо выключает оба);
- таймер выключения 1–24 ч и датчик оставшегося времени;
- состояние читается из кондиционера каждые 2 с, поэтому изменения с ИК-пульта тоже видны в HA.

Эко, iFeel и Очистка с пульта в статусе по UART не видны и не поддерживаются.

## Быстрый старт

1. Скопируйте [rusklimat-ac.yaml](rusklimat-ac.yaml) в ESPHome Device Builder как конфиг нового устройства.
2. Добавьте в `secrets.yaml` ключи из [secrets.example.yaml](secrets.example.yaml).
3. Первую прошивку залейте по USB, дальше — по воздуху.
4. В Home Assistant устройство найдётся само; при добавлении введите `api_encryption_key`.
5. По желанию — карточка для дашборда: [ha-card.yaml](ha-card.yaml)
   (`entity_id` в ней поправьте под свои из «Инструменты разработчика → Состояния»).

## Подключение

ESP32 подключается к разъёму штатного Wi-Fi-модуля: GND, питание, TX и RX. UART — 9600 8N1.

| Кондиционер | ESP32-WROOM |
|---|---|
| TX кондиционера | GPIO16 (RX ESP) |
| RX кондиционера | GPIO17 (TX ESP) |
| GND | GND |
| +5 В | 5V / VIN платы |

> **Уровни сигналов.** ESP32 работает на 3,3 В, и его входы не рассчитаны на 5 В. Если на TX кондиционера 5 В,
> поставьте на RX ESP делитель (например, 1 кОм + 2 кОм) или преобразователь уровней. Перед подключением
> измерьте напряжение мультиметром.

## Конфигурация компонента

```yaml
external_components:
  - source: github://yuschkof/rusklimat-esphome@v1.0.0
    components: [rusklimat]

uart:
  id: ac_uart
  tx_pin: GPIO17
  rx_pin: GPIO16
  baud_rate: 9600

climate:
  - platform: rusklimat
    id: main_ac
    name: "Кондиционер"
    uart_id: ac_uart
    update_interval: 2s  # по умолчанию
    # всё ниже необязательно — ссылки на template-сущности
    display_switch: sw_display
    ionizer_switch: sw_ionizer
    sleep_switch: sw_sleep
    quiet_switch: sw_quiet
    turbo_switch: sw_turbo
    timer_number: num_timer
    timer_remaining_sensor: sens_timer_remaining
```

Переключатели, таймер и датчик остатка — обычные `template`-сущности. Их действия вызывают методы
`set_display()`, `set_ionizer()`, `set_sleep()`, `set_quiet()`, `set_turbo()`, `set_timer_hours()`,
а компонент публикует в них фактическое состояние из статуса кондиционера. Полный пример — [rusklimat-ac.yaml](rusklimat-ac.yaml).

> **Важно:**
> - у template-переключателей ставьте `restore_mode: DISABLED`, иначе при загрузке ESP выполнит
>   `turn_off_action` и отправит лишнюю команду;
> - ESPHome заменяет кириллицу в имени сущности на `_`, поэтому кириллические имена одной длины конфликтуют
>   («Тихий» и «Турбо» → `_____`). Отсюда «Тихий режим» в примере.

## Другие платы

В [rusklimat-ac.yaml](rusklimat-ac.yaml) меняются только блоки `esp32` / `esp8266`, `uart` и при необходимости `logger`.
Остальное — без изменений.

### ESP32-C3 SuperMini / SuperMini Plus

Лог идёт через встроенный USB, поэтому аппаратный UART свободен под кондиционер.
GPIO2, 8 и 9 — strapping-пины (на 8 светодиод, на 9 кнопка BOOT), их не используйте.

```yaml
esp32:
  board: esp32-c3-devkitm-1
  framework:
    type: esp-idf

uart:
  id: ac_uart
  tx_pin: GPIO21  # → RX кондиционера
  rx_pin: GPIO20  # ← TX кондиционера
  baud_rate: 9600

wifi:
  # ...ssid/password/ap как в примере...
  # У многих SuperMini слабая антенна и просадки питания при полной мощности передатчика.
  # Если Wi-Fi отваливается — уменьшите мощность:
  output_power: 8.5dB
```

### ESP32-S3 (DevKitC-1 и аналоги)

```yaml
esp32:
  board: esp32-s3-devkitc-1
  framework:
    type: esp-idf

uart:
  id: ac_uart
  tx_pin: GPIO17
  rx_pin: GPIO18
  baud_rate: 9600
```

### ESP8266 (Wemos D1 mini и аналоги)

У ESP8266 полноценный UART только один, и он нужен кондиционеру, поэтому лог по проводу отключается —
смотрите его по Wi-Fi в ESPHome Device Builder.

```yaml
esp8266:
  board: d1_mini

logger:
  baud_rate: 0  # освободить UART0 под кондиционер

uart:
  id: ac_uart
  tx_pin: GPIO1  # TX
  rx_pin: GPIO3  # RX
  baud_rate: 9600
```

На время прошивки по USB отключайте плату от кондиционера: USB-UART и кондиционер сидят на одних и тех же пинах.

## Протокол

9600 8N1. Кадр: `AA <len> <type> ... <crc>`, `len` — число байт после него без CRC,
CRC — сумма всех предыдущих байт по модулю 256.

Запрос статуса (каждые `update_interval`): `AA 02 01 AD`.

Статус (type `0x01`, от кондиционера), команда (type `0x02`, от ESP) и ACK на команду (type `0x02`, от кондиционера) —
по 22 байта:

| Байт | Значение |
|---|---|
| 3 | питание: `00` выкл, `01` вкл |
| 5 | вертикальные жалюзи: `00` качание, `06` стоп |
| 6 | `0x02` горизонтальные жалюзи; в команде базово `0x18` |
| 7 | режим: `00` auto, `01` cool, `02` dry, `03` heat, `04` fan |
| 8 | флаги, независимые: `0x10` дисплей, `0x08` турбо, `0x04` тихий, `0x02` ионизатор, `0x01` сон |
| 9 | вентилятор: `00` auto, `01`–`03` low–high (флаги [8] скорость не меняют) |
| 10 | уставка, °C |
| 11 | температура в комнате, °C (в команде `00`) |
| 12 | таймер: `02` активен, `00` нет |
| 13 | таймер, часы (может хранить старое значение и при выключенном таймере) |
| 14 | таймер, минуты |
| 21 | CRC |

ИК-пульт при каждом нажатии отправляет кондиционеру всё своё состояние целиком. Поэтому нажатие любой кнопки
на пульте может сбросить флаги, включённые из Home Assistant (например, Тихий).

## Отладка

| `logger: level:` | Что видно |
|---|---|
| `INFO` | первый статус после загрузки, предупреждения (CRC, неизвестные значения) |
| `DEBUG` | изменения статуса побайтно (`[8]:10->14`) и отправляемые команды |
| `VERBOSE` | ещё и ACK кондиционера на каждую команду |
